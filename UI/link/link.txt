Investing UI

Live (the Refresh button works):
    http://127.0.0.1:8765/#IREN
    Double-click start-investing-ui.cmd. It starts the UI server and opens the page.
    Keep its window open while you use the page; close it to stop the server.
    investing-ui.url opens the same address while the server is running.

Offline (shows the last saved data; Refresh is unavailable):
    file:///C:/Users/naory/Documents/git/investing/UI/index.html#IREN
    investing-ui-offline.url opens it.

Pages of each asset:
    #IREN                 its first page, with a box for each section
    #IREN/graphs/1Y       graphs (also /3M and /1D)
    #IREN/ratios          fundamental ratios
    #IREN/news, #IREN/info, #IREN/analyst   empty for now

The page reads UI\data\, which each asset's pipeline writes (IREN's is
UI\asset\iren_page\update_iren_page.py). The Refresh button runs the current asset's
pipeline through UI\server.py.

Add an asset:
    In the page: Your assets > + Add asset, type the ticker, Add. The server runs
    the asset-page skill (claude -p "/asset-page TICKER") in the background.
    Or in Claude Code: /asset-page TICKER.

Delete an asset: Your assets > the ✕ next to it. Its folder moves to UI\asset\_deleted\.
    Bring it back: .venv\Scripts\python.exe UI\pipeline\new_page.py restore TICKER
The skill lives in .claude\skills\asset-page\ and uses UI\pipeline\new_page.py.
