The page reads UI\data\, which each asset's pipeline writes (IREN's is
UI\asset\iren_page\update_iren_page.py). The Refresh button runs the current asset's
pipeline through UI\server.py.

Add an asset:
    + Add asset at the top, type the ticker, Add. The server runs UI\pipeline\new_page.py
    (a Python script). Comparison series come from fixed rules; change them in
    UI\asset\<ticker>_page\config.json. The asset joins My watchlist.
    Or in Claude Code, /asset-page TICKER lets Claude choose them.

Remove an asset: My watchlist > the ✕ at the right of its line (or Delete on its page).
    Its folder moves to UI\asset\_deleted\.
    Bring it back: .venv\Scripts\python.exe UI\pipeline\new_page.py restore TICKER
The skill lives in .claude\skills\asset-page\ and uses UI\pipeline\new_page.py.

Analyst rating changes (#IREN/ratings, the button in the Analysts box on #IREN/ratios):
    Every analyst update of the past year, newest first, with the firm's reason for each
    change of rating or price target. The table is kept in
    UI\asset\<ticker>_page\analyst_table.json. On Refresh, the server compares Yahoo's
    table with it; only when there are new changes does it start Claude in the background
    (the rating_change_cause_searcher skill) on just those, then adds their reasons.
    Adding an asset does the same for its whole past year. The page tells you while the
    search runs. By hand in Claude Code: /rating_change_cause_searcher IREN.
    To stop the buttons from starting Claude (domains and reasons), set AUTO_AI = False in
    UI\server.py.
